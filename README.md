# Simulacion

5B Ingenieria Sistemas Computacionales 

Integrantes 

Carlos Emir Novelo Albornoz,
Orlando Cordova Herrera

En este programa se llevará a cabo una simulación del funcionamiento básico de una gasolinera, enfocada principalmente en el proceso de abastecimiento de combustible a una cantidad determinada de vehículos. La simulación permitirá representar de manera sencilla cómo se realiza la carga de combustible y cómo se atiende a los diferentes vehículos que llegan a la gasolinera.
